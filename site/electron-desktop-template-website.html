IPC contracts

新增方法只改三处；handler 缺失，编译期报错。

  • preload 必须是 CJS。 sandbox 下只能经子树路径导入，否则 window.api 会静默消失。
  • 通道命名固定。 {domain}:{action} / {domain}:event:{name} / {domain}:stream:{event}。
  • 响应统一 unwrap。 订阅返回 unsubscribe，流式事件有明确生命周期。

05QUICK START

五分钟，跑起来。

需要 Node 26 LTS 与 pnpm 12。首次安装会下载 Electron 二进制（约 100+ MB）——安装钩子失败会明确报错，不会留下「能装不能跑」的状态。

  • NODE ≥ 26 LTS
  • PNPM ≥ 12
  • OS Windows / macOS / Linux

浏览器模式用 pnpm dev:web，不启动 Electron 窗口。

模板验收指南
01启动模板 
$pnpm install
$pnpm dev

打开 Electron 窗口。内置首页在 src/renderer/routes/home.tsx。

02派生新项目 
$pnpm init:template --name "My App" --app-id com.me.myapp \
  --protocol myapp --owner me --repo myapp --author "Me"
$pnpm install --frozen-lockfile
$pnpm check:brand

命令幂等；可先加 --dry-run 预览会改哪些文件。
